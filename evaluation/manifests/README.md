# Experiment manifests

Generated catalogs and split manifests are ignored by default because dataset terms
and identity annotations must be reviewed before publication. This directory keeps
only the instructions in Git.

For every reported result, retain an immutable copy of the exact catalog,
`train.csv`, `validation.csv`, `test.csv`, and `split_summary.json` in approved project
storage. Record the test-manifest SHA-256 from the evaluator in the final report.
